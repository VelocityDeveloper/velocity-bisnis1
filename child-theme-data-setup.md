# Alur Isi Data Child Theme Bisnis1

## Customize

1. Isi **Customize Velocity Theme**:

   1. **Site Identity**: logo, site title, tagline, site icon.
   2. **Header Content**: jam kerja, email, telepon dan whatsapp.
      - Apabila tidak ada data dari client, ambil dari form isian website, jika jam kerja tidak ada di keduanya bisa di isi dummy.
2. **Social Media**: social media link facebook, twitter, instagram, youtube, dan linkedin.
   - Apabila tidak ada data dari client, isi link dengan link default dari masing-masing social media.
3. **Home Big Banner**: banner image, banner title, banner sub title.
4. **Home Small Banner**
   - Isikan maxsimal 3 banner. Isi tiap banner: banner image dan banner title.
   - Apabila tidak ada data dari client, buatkan contoh banner yang sesuai dengan bisnis perusahaan.
5. **Home Service**: title, service di isi: icon dan content.
   - Ada **6 layanan** yang harus diisi.
   - Apabila jumlah layanan dari client kurang dari 6, maka buatkan contoh layanan yang sesuai dengan bisnis perusahaan.
6. **Home Client**: title dan client logos.
7. **Theme Color**: sesuaikan dengan warna logo
8. **Background**: set background color jadi **#F5F5F5**

## Widgets

* Pada **Main Sidebar**: widgets pencarian, widgets recent posts, dan text: title "statistik pengunjung" dan content statistik \[velocity-statistics].

## Gallery

* Aktifkan fitur **Gallery Post Type** di Velocity Addon.
* Gunakan shortcode **VD Gallery** untuk tampilan halaman gallery.

## Logo Header

* Atur ukuran image logo yang di-render menjadi **190 × 52 px**.
* Apabila warna logo tidak kontras dengan background belakangnya, berikan **background putih**.

## Halaman Home

* Set halaman **Home** mengambil template **"Home Template"**.
